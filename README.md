# 飞行大战 PlaneFight

基于 Cocos Creator 3.8.8 开发的 2D 飞行射击小游戏，独立完成玩法设计、脚本开发与资源接入，可完整跑通一局对战流程。

## 玩法

- 开始界面点击「开始」按钮进入游戏场景
- 触摸或拖拽控制战机移动，战机自动连续射击
- 击落敌机累计得分；被敌机撞到损失一条生命，生命耗尽本局结束
- 击落敌机有概率掉落道具：**双发**（一定时间内双排弹道）、**炸弹**（在界面点击炸弹按钮清屏）
- 游戏结束面板显示本局得分与历史最高分，最高分通过 `localStorage` 持久保存；可点击重开
- 支持暂停与继续

## 运行环境

- **Cocos Creator 3.8.8**（工程 `package.json` 已锁定该版本，请使用同一版本打开，避免资源重新序列化带来的冲突）
- 无其他依赖；预览使用编辑器自带的浏览器预览，无需额外安装运行环境
- 推荐在桌面浏览器中预览，触摸操作在该分辨率下用鼠标拖拽替代

## 如何运行

1. 安装 **Cocos Creator 3.8.8**：打开 Cocos Dashboard → 编辑器 → 找到 3.8.8 并安装
2. 在 Dashboard 点击「项目 → 打开其他项目」，选中本仓库根目录（即打开后能看到 `package.json` 与 `assets` 文件夹的那一层），点击「打开」
3. 首次打开编辑器会自动导入并编译资源，等待资源管理器停止刷新（`library` 目录由编辑器自动生成，仓库中不包含）
4. 在「资源管理器」中展开 `assets/Scenes`，双击 `01-Start.scene` 打开开始场景
5. 点击编辑器右上角的「浏览器预览」按钮（或按 `Ctrl + P`），在浏览器中运行游戏

> 预览前必须先在编辑器里打开一个场景，否则没有可运行的内容。

## 构建 Web / 微信小游戏

在构建面板的「包含的场景」中同时勾选 `01-Start` 与 `02-GameScene`。开始按钮通过场景名加载游戏场景（`director.loadScene("02-GameScene")`），漏勾 `02-GameScene` 会导致构建产物中点击开始后无法进入游戏。

## 目录结构

```
assets/
  Animations/   飞机待机、受击、坠毁等动画剪辑
  Audio/        背景音乐与音效（含 Bg 子目录）
  Image/        战机、敌机、子弹、道具、界面图片与图集
  Prefabs/      两种子弹、三种敌机、两种道具的预制体
  Scenes/       01-Start 开始界面 / 02-GameScene 游戏场景
  Scripts/      游戏脚本（含 UI 子目录）
settings/       项目设置：设计分辨率、物理碰撞分组与碰撞矩阵
```

## 技术要点

- 设计分辨率 480 × 850（竖屏）
- 物理碰撞分组 `Bullet` / `Enemy` / `Player` / `Reward`，通过碰撞矩阵过滤需要检测的组合；碰撞处理使用 2D 碰撞体的 `BEGIN_CONTACT` 事件
- 敌机与道具由 `EnemyManager` 用不同间隔的定时器持续生成，子弹与敌机均以预制体动态实例化
- 战机的单发 / 双发弹道切换、无敌帧、生命值、暂停与恢复集中在 `Player` 与 `GameManager` 中管理；分数、炸弹数量与最高分记录由 `GameManager` 统一维护
- 音效通过单例 `AudioMgr` 统一播放，支持一键暂停与恢复全部音频
- 界面拆分为 `StartUI`、`ScoreUI`、`LifeCountUI`、`BombUI`、`GameOverUI`，各自只负责本区块的显示刷新

## 版本管理说明

`library/`、`temp/`、`build/`、`profiles/`、`local/` 为编辑器生成的本地缓存、构建产物与本地编辑器状态，已在 `.gitignore` 中排除，克隆后由编辑器自动重新生成，无需也不应提交。
